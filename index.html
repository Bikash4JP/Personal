MobiLedger

Bilingual (EN/JP) personal accounting app for iOS and Android. Features double-entry bookkeeping, automatic P&L / Balance Sheet / Trial Balance generation, PDF export, multi-currency support.

Problem
Small proprietors and individuals need proper double-entry books they can keep on a phone, with accounting terms in both English and Japanese.

Reports are computed live from the entries rather than stored. 56 built-in ledgers with 60+ English–Japanese account names, PDF ledger statements, and a demo mode that works without a backend. Dates are parsed as strings to avoid timezone drift on phones.

DevPulse

Engineer productivity hub that automatically collects messages from Slack, LINE, and Gmail, summarizes them daily using AI, generates PDF reports, and delivers push notifications. Full CI/CD pipeline, deployed to AWS EC2.

Problem
Work messages are spread across Slack, LINE and Gmail, so an engineer has no single daily overview.
My role
Full-stack developer: Express and Prisma backend, React Native (Expo) app, Docker and AWS EC2 deployment.
Approach
OAuth 2.0 for Slack and Gmail, a LINE webhook, scheduled Gemini summaries with a rule-based fallback so a Gemini outage doesn't break the daily summary, and OAuth tokens stored encrypted with AES-256-GCM. GitHub Actions builds and deploys to EC2 on every push.

Planning GitHub ↗

VaultPass

Open-source, zero-knowledge password manager planned for iOS, Android and web. The design keeps the server to ciphertext only: encryption and decryption happen on the user's device. Currently in the research and design phase.

Problem
Breaches of cloud password managers show the risk of servers that can read, or hold decryptable, vault data. The aim is an open, verifiable alternative with first-class Japanese support.
My role
Product definition, architecture, engineering and security rules, repository and infrastructure setup.
Status
Pre-alpha, no application code yet. Done so far: a Japanese design-document set (requirements, basic and detailed design, database, API, infrastructure, test and operations) and a PostgreSQL environment in Docker Compose. Planned stack: React Native + Expo, Node.js + Express, PostgreSQL + Prisma, Argon2id key derivation, AES-256-GCM.
